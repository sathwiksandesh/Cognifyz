# 🚀 Cognifyz Internship — Python Projects & Tasks

**Internship Submission by Sidhantam Sathwik Sandesh**

This repository contains the completed tasks undertaken as part of the **Cognifyz Technologies Internship Program**.

The projects cover fundamental and intermediate concepts in **Python programming, problem solving, file handling, web scraping, data visualization, and automation**. The tasks are organized into different levels and folders for easy navigation and evaluation.

---

## 📌 Repository Overview

The internship tasks are divided into **three levels**, with each level focusing on progressively more advanced Python concepts.

### Level 1 — Python Fundamentals

Basic programming concepts, string manipulation, validation, and mathematical operations.

### Level 2 — Intermediate Python

Interactive programs, algorithms, password validation, sequences, and file handling.

### Level 3 — Advanced Python Applications

Web scraping, data visualization, and file automation.
